## T1-4. Повторное подтверждение — идемпотентность

**Вход данные:** 
{
  "order_id": "ord_1001",
  "recipient": "clinic_medservice",
  "purpose": "Приём терапевта",
  "amount": 2500.00,
  "currency": "RUB"
}

**Действия:** создать платёж; подтвердить его с ключом `confirm_0001`; после получения результата повторить тот же запрос подтверждения для того же `payment_id`, с тем же телом и тем же ключом `confirm_0001`. Проверить хранилище, журнал шлюза и аудит.
**Ожидание:** `DUPLICATE_REQUEST` и HTTP `200`
**Факт:** 
{
  "status": "ERROR",
  "error_code": "VALIDATION_ERROR",
  "errors": [
    {
      "field": "order_id, recipient",
      "code": "DUPLICATE_ORDER"
    },
    {
      "field": "idempotency_key",
      "code": "DUPLICATE_REQUEST"
    }
