# Платёжный сервис Med-Service (CLI-прототип)

Это консольный прототип платёжного сервиса для клиники. Прототип эмулирует работу платёжного шлюза, валидирует данные, поддерживает идемпотентность и ведёт аудит событий.

## Требования
- Установленный Python 3.8 или выше.
- Дополнительные библиотеки не требуются (используется только стандартная библиотека Python).

## Структура проекта
- `05_app.py` — основной файл приложения (CLI).
- `gateway_emulator.py` — модуль эмуляции банковского шлюза.
- `payment.json` — пример входящего запроса на оплату.
- `payments_out.csv` — база данных (журнал платежей), создается автоматически.
- `events.log` — журнал аудита (история смены статусов), создается автоматически.
- `01_данные/recipients.csv` — справочник активных получателей.

## Как запускать

Скрипт поддерживает три команды: `create`, `status` и `cancel`.

### 1. Создание платежа (create)
Так как прототип консольный, `Idempotency-Key` (который в реальном API передается в HTTP-заголовке) мы передаем вторым аргументом.

**Команда:**
`python 05_app.py create payment.json idem_001`

**Что произойдет:**
1. Скрипт прочитает `payment.json` и проверит данные по правилам V-1...V-8.
2. Сгенерирует `payment_id` и токен подтверждения.
3. Эмулирует запрос в банк.
4. Запишет результат в `payments_out.csv` и `events.log`.

### 2. Проверка статуса (status)
Возвращает текущий статус платежа и историю его изменений.

**Команда:**
`python 05_app.py status pay_demo_1001`

### 3. Отмена платежа (cancel)
Отменяет платеж, если он еще не был успешно оплачен (статус `CREATED` или `PENDING`).

**Команда:**
`python 05_app.py cancel pay_demo_1001`

## Как тестировать разные сценарии шлюза
Эмулятор выбирает результат в зависимости от `order_id` (по хэшу).
Чтобы проверить разные сценарии, меняйте `order_id` в `payment.json`:

- **Успех (SUCCESS):** `ord_1001`
- **Недостаточно средств (INSUFFICIENT_FUNDS):** `ord_1007`
- **Карта отклонена (CARD_DECLINED):** `ord_1008`
- **Таймаут (TIMEOUT -> PENDING):** `ord_1009`

*Внимание:* По умолчанию в `gateway_emulator.py` стоит задержка таймаута 600 секунд (10 минут) по ТЗ. Для быстрого тестирования этого сценария измените переменную `timeout` на `3` секунды.
